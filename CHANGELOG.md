# Changelog

## 0.1.0 — first release

Initial release for Minecraft: Bedrock Edition 1.26.60 / LeviLamina 26.60.x (client).

- Tooltip for blocks, entities and fluids with the providers of the original Jade (core, universal, vanilla, harvest, accessibility, debug)
- Settings screen with search, preview, themes, overlay position and config profiles
- Bedrock additions: dyed water color in cauldrons, composter level, respawn anchor charges, add-on pack names
- C API for other mods (`include/jade/JadeApi.h`)
- English, Japanese and Chinese (Simplified / Traditional)
